# Ex. 10 - Developing Server-Side Application using Node.js

Web Technology Lab (23CS2049).

HTTP server using the built-in `http` module (`server.js`) and a routed version for /home and /about (`server-routes.js`).

**Run:** `node server.js` then open http://localhost:3000

Live page: https://noelms.github.io/Exp10_Web_Tech/

The page shows the source and output captured from a real local run; this exercise needs a local server or MongoDB, so it cannot run on GitHub Pages itself.
